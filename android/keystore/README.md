# Debug Signing Keystore

This directory holds the **debug** signing keystore for the Android build of `brain3-companion`. It is **not** the release keystore — release signing is covered by `[2C-15]` and is generated and held by L locally, never committed.

## What lives here

| File | Tracked in git? | Purpose |
|---|---|---|
| `debug.keystore` | **No** (gitignored) | Signs `assembleDebug` builds so the resulting APK installs on physical devices and emulators. |
| `README.md` | Yes | This file. |

The keystore is intentionally gitignored. Fresh clones — and any future CI build — must regenerate it locally with the command below. Trade-off: a small amount of friction per clone in exchange for not committing private signing material to the repo, even one with a fixed conventional password.

## Regenerating the debug keystore

Run this from the repo root (`brain3-companion/`):

```sh
keytool -genkey -v -keystore android/keystore/debug.keystore -storepass android -alias brain3-companion-debug -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=BRAIN Companion Debug, OU=Flux Meridian, O=Flux Meridian, L=Unknown, S=Unknown, C=US"
```

`keytool` ships with the JDK (Android Studio bundles its own under `jbr/bin/` or `openjdk/.../bin/`). If `keytool` is not on `PATH`, point at the JDK that Android Studio uses for Gradle builds — using a different JDK is fine for keystore generation, but stay consistent within a project.

## Convention notes

- **Alias:** `brain3-companion-debug`
- **Store password:** `android`
- **Key password:** `android`
- **Validity:** 10,000 days (~27 years)
- **Algorithm:** RSA 2048

The `android` / `android` password pair is the long-standing Android-tooling convention for debug keystores. The security boundary here is "you cannot reinstall over a debug-signed app on someone else's device without re-signing," which is exactly the property we want — nothing about this keystore protects production user data, because the debug build never sees production user data.

## How Gradle finds it

`android/app/build.gradle` declares a `signingConfigs.debug` block that points at `../keystore/debug.keystore` (relative to `android/app/`). Both `assembleDebug` and Android Studio device runs use this signing config automatically. If the file is missing at build time, Gradle will fail with `Keystore file not found` — regenerate per the command above.

## Release signing

See `[2C-15]` for the release keystore process. Release signing material is generated by L, stored outside the repo, and never enters version control under any circumstance.
